GoFlow Pay — management

API

  • /api/v1 — REST API v1 (legacy, требует JWT)
  • /api/v2 — REST API v2 (требует JWT)
  • /api/v2/docs — Swagger UI для API v2

Интерфейсы

  • / — главная страница
  • /reserved/ — резервная копия главной страницы
  • /legacy — старый SPA-интерфейс (работает через /api/v1)
  • /documentation — README.md проекта

Служебные страницы

  • /admin — Adminer (только из локальной сети, Basic Auth)
  • /status — статус NGINX
  • /health — liveness gateway
  • /ready — readiness gateway (связь с gRPC-сервисами)
